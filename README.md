
# 晚 6 点打卡提醒 —— 方案说明

## 目标
每天 **18:01** 自动弹出提示，提醒下班打卡。可由用户确认后实施。

---

## 方案对比

| 方案 | 弹窗样式 | 可靠性 | 是否需要常驻 | 实施难度 |
|---|---|---|---|---|
| A. 任务计划程序 + PowerShell MsgBox | 简单 Windows 对话框 | ★★★★★ | 否 | 低 |
| B. 任务计划程序 + Python tkinter | 可自定义（标题/按钮/图标） | ★★★★★ | 否 | 中 |
| C. Python 脚本常驻 + 定时弹窗 | 可自定义 | ★★★（依赖电脑一直开） | 是 | 中 |

> **推荐方案 B**：可靠性最高（由 Windows 任务计划程序兜底，即使忘了开脚本也会触发），弹窗可定制，工作目录本来就有 Python 环境。

---

## 推荐方案 B 详解

### 1. 触发机制：Windows 任务计划程序
- 创建一个任务，每天 18:01 触发一次
- 即使电脑当时锁屏/休眠，也会弹出通知（系统层面处理）
- 不需要写开机自启、不需要常驻进程

### 2. 弹窗：Python + tkinter
- 用 `tkinter` 写一个小窗口，居中显示在最上层
- 标题如 "⏰ 下班打卡提醒"
- 正文如 "该打卡啦！别忘了哦"
- 按钮：「已打卡 ✓」（关闭窗口）/「5 分钟后再提醒」（延时弹一次）
- `tkinter` 是 Python 标准库，无需额外安装

### 3. 文件清单
```
schwork/
├── remind.py        # 弹窗脚本（Python）
├── install.bat      # 一键注册到任务计划程序（双击运行）
├── uninstall.bat    # 一键移除任务
└── README.md        # 本文档
```

### 4. 工作流程
```
18:01 → 任务计划程序 → 启动 remind.py → 弹出置顶窗口 → 用户点击
```

## 需要你确认的几点

1. **触发时间**：固定 18:01，还是要区分工作日（周一到周五）？ 开机运行的时候则正常触发
   - 工作日更合理（周末不用打卡）
2. **弹窗文案**：用默认的「下班打卡提醒 / 该打卡啦！」，还是想自定义？默认的
3. **再提醒按钮**：要不要「5 分钟后再提醒一次」这种功能？ 要
4. **提前提醒**：要不要在 17:55 提前弹一次作为预警？ 不用
5. **休息日/节假日**：暂不处理（每年手动调整任务，或后续加配置文件）

---

## 注意事项

- **电脑关机**：如果 18:01 时电脑是关的，任务计划程序会**错过当天**，不会补弹。这是 Windows 任务计划程序的特性，无法绕开。如有需要可以改成「开机后补弹」逻辑。不需要
- **Python 环境**：当前机器已检测到 Python 环境，使用 `python` 命令即可。
- **测试**：安装后可以用「立即运行」按钮测试弹窗，不需要等到 18:01。
